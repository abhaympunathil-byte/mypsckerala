File Schema Guidelines

1. Questions Format

To import multiple choice questions, the file must include the following columns:

  • class_name (e.g., Class 10)
  • subject_name (e.g., Chemistry)
  • question_text (The question description)
  • option_a, option_b, option_c, option_d
  • correct_answer (Must be A, B, C, or D)
  • explanation (Reasoning / details)

2. Study Notes Format

To import notes and summaries, the file must include the following columns:

  • class_name (e.g., Class 10)
  • subject_name (e.g., Chemistry)
  • title (The title of the note)
  • content (Rich text or detailed text summary)
